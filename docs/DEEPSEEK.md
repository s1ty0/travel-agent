# DeepSeek 本地接入

初始阶段仅使用 DeepSeek。此接入只把自然语言中的目的地、预算、出发地提取为候选字段，不生成可信行程、不联网搜索，也不调用购买工具。候选字段必须来自原文连续片段，并再次经过 M1 规则校验；语义仍需用户确认。

## 本地配置

将 `.env.example` 复制为 `.env`，在本地填写 `DEEPSEEK_API_KEY`。用户本轮提供的密钥已写入当前工作目录的忽略文件，无须再发一次。示例文件只有空密钥，真实文件不会进入 Git。

`DEEPSEEK_MODEL` 应是官方账号可用的模型。本次文档核验与调用使用 `deepseek-flash`；模型标识将来可调整。默认读取超时 30 秒、最多输出 512 tokens，配置上限 2048。读取超时是 HTTP 读写限制，不是整段任务的绝对时间上限。

```powershell
uv sync --locked --cache-dir .cache/uv
"从上海出发去南京附近，预算5000以内" | uv run --cache-dir .cache/uv --env-file .env --no-sync travel-agent-deepseek --live
```

需要 UTF-8 管道输入；旧版 Windows PowerShell 可先设置 `$OutputEncoding = [System.Text.UTF8Encoding]::new()`。程序明确以 UTF-8 读取标准输入并输出 JSON。实际旅行内容建议通过标准输入或本地文件管道传入，减少命令历史中的个人资料。

CLI 没有 `--live` 时不会发送请求。每次运行最多一个模型请求，无自动重试；真实调用会按供应商计费。输出 token 上限不是人民币费用硬上限，费用还依赖输入、缓存和模型计价。扩大调用前需要确定每次规划的服务成本上限。

## 权限与错误处理

- 官方请求主机固定为 `https://api.deepseek.com`，不跟随重定向、不读取环境代理配置，不把密钥发送到可任意配置的主机。
- 读取密钥仅在显式 CLI 调用时发生；离线 CLI、现有本地 HTTP API 和测试不自动读取 `.env` 或联网。
- HTTP 401、402、403、429 和连接/超时分别返回安全错误码；不输出响应正文、请求头或密钥。
- 空白/超长输入、超大响应、JSON 结构错误、额外字段、未完成生成和非原文片段均失败关闭。没有自动“修复并重试”的额外计费。
- 记录实际返回的模型与 token 用量；缺少用量时保留 null，不伪造为零。当前没有汇率和价格表，不估算账单金额。
- `live_verified=false` 表示未核实旅游事实，不表示没有调用真实模型。模型连接验证与旅游事实核验是两件事。
- 还没有对外开放付费模型 HTTP 路由。加入网页调用前必须先实现身份、限流、任务预算和私有数据隔离。

默认测试使用模拟传输，不消耗用户额度，不需要密钥。真实模型验证结果单独写在忽略目录 `artifacts/qa/`；开发日志只保留非敏感摘要。真实搜索和地图接入仍未完成，不把模型记忆当作实时证据。

依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。该文档支持 JSON 输出和输出长度设置；本地仍要检查 JSON 内容、完成状态与字段规则，不能只信“返回了 JSON”。
