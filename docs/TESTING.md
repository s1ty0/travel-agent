# 测试与上线门禁

## 当前可运行的检查

```powershell
uv sync --locked
uv run --no-sync python scripts/check.py
uv build --out-dir artifacts/dist
```

统一入口按顺序执行：静态检查、格式检查、依赖一致性、冒烟、固定样例回归、当前全部离线测试和分支覆盖。任何一步失败立即返回非零退出码；修复后重新跑完整入口。

固定回归之后增加冻结规划验收 `scripts/evaluate_planning.py`，先验证 10 条用例字节哈希，再检查模拟规划结果；失败即停止后续门禁，结果保存在 `artifacts/qa/planning-acceptance.json`。同次开发的合成契约已成为已知回归，不是第三方盲测或真实独立保留集，不能替代正式效果评估。

Markdown 中的 Python 示例同样需要通过格式门禁。新增文档先显式执行 `uv run --no-sync ruff format --check <文档路径>`，并在文件暂存后执行最终统一检查；不能只依赖新增文档前的通过结果。格式失败也不能用关闭检查来放行。

统一入口现会显式枚举仓库根目录和 `docs/` 中的 `.md` 文件交给格式器，包括尚未 Git 跟踪或暂存的新文档，不再只依赖默认发现。不会额外枚举 `runtime/`、`artifacts/` 等私有生成目录；其他新增文档目录仍需显式检查，扩展工程时同步更新范围。回归会在临时 Git 仓库中重现未暂存文档错误，确认检查返回失败并停止后续检查。

冒烟包括真实本地 HTTP 进程启动、健康检查、需求解析、费用核算与 CLI。回归覆盖固定的 20 条预算/目的地样例；全量还覆盖异常输入、日期冲突、金额精度、人数/天数/房晚、税费、未知成本和只读边界。覆盖率门槛暂设 85%，不能替代业务断言。

M2 模型适配增加 DeepSeek 模拟协议冒烟、JSON/完成状态/原文片段校验、错误脱敏、限流/权限/网络失败、配置边界、CLI 显式启用和 UTF-8 管道回归。默认检查不加载真实密钥、不消耗模型额度。真实调用结果单列；一次字段提取通过不等于搜索或 Agent 集成通过。

M2 来源适配继续覆盖：DeepSeek 搜索、高德城市/周边 POI、步行路线的模拟协议；单位与坐标系、分页上限、空/部分结果、链接过滤、HTTP/业务错误、元数据和 SQLite 索引。资源泄漏及其导致的未处理析构异常警告视为失败，不能通过屏蔽警告处理。真实查询仅用公开通用地点，限量执行，并单独记录来源连通状态；接口成功不代表当前旅游事实已核实。

资料层加入 10 条合成证据回归，覆盖逐字匹配、重复歧义、Unicode 位置、只有链接、摘要、日期和恶意指令。全量另测独立共享/保存授权、未共享资料不进入模型、快照大小/版本/哈希、路径边界、删除及无网络 CLI/API。合成样例已经用于开发，不能充当独立保留集；引文匹配不替代事实真实性或语义充分性验收。

## 发布记录与放行

每个候选版本记录提交 SHA、依赖锁文件、环境、测试清单、命令、通过/失败/阻塞数、报告位置、已知问题及回滚方式。修复后在最终候选版本重跑全部适用测试；不使用旧提交的通过结果放行新代码。

所有适用检查完成且通过、阻塞清零后，才进入正式上线。上线后再跑生产只读冒烟；失败时回滚并保留证据。当前没有自动部署工作流，推送代码不触发上线。
