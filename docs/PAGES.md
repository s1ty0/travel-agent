# 受控网页正文读取

本模块读取 DeepSeek Fetch 转换后的 Markdown 正文，并定位逐字引文。成功表示收到了可用正文，不表示原始 HTML 完整、来源身份已认证或旅游事实已核实。

## 开放范围

目前有独立 CLI、Python 适配器和按输入授权的单 Agent 工具，没有对外 HTTP 路由。规划默认关闭网页工具，只有明确设置 `page_urls` 才允许读取并送入模型；普通导入链接或搜索结果不会自动扩大权限，详见 [规划说明](PLANNER.md)。

本轮审查的精确读取地址：

| 地址 | 本地分类 | 仍不能据此认定 |
| --- | --- | --- |
| `https://www.njmuseum.org.cn/zh/visitIndex` | 场馆站点候选 | 没有独立取得域名官方身份认证；不能单凭页面名称或搜索排名认证。 |
| `https://www.nanjing.gov.cn/njxx/202407/t20240704_4706024.html` | 政府门户历史新闻页 | 页面来自 2024 年，且是新闻信息；不能直接推成当前场馆规则或一手场馆公告。 |

只接受表中完整地址。其他协议、域名、端口、子域、路径、查询和片段均拒绝，不做模糊匹配。网址审查有效期到 2026-11-15，过期停止，后续重新核对再更新。读取范围不是全文归档授权。

所有 HTTP 请求只发往固定 DeepSeek Fetch 端点，本地不请求目标网页或页面内链接，不发送目标网站 Cookie、登录态或用户旅行需求。供应商在下游如何解析 DNS、处理跳转及访问策略仍由供应商负责；这不是本项目已完成任意网页抓取的 SSRF 安全验收。

## 显式使用

```powershell
uv sync --locked --cache-dir .cache/uv
'{"url":"https://www.njmuseum.org.cn/zh/visitIndex","quotes":[{"quote":"周一闭馆"}]}' | uv run --no-sync --env-file .env travel-agent-page --live
```

输入是 UTF-8 JSON，最多 8192 个字符，最多 10 条引文，每条 2～300 个字符。无 `--live` 不读取密钥、不联网。一次命令最多一次请求，不重试、不直连回退、不跟随本地 HTTP 重定向，不升级或充值。

默认输出和自动审计都只包含元数据、引文定位结果及费用状态，不含输入引文、供应商标题或正文。确需查看正文时加 `--include-content`；这只改变终端输出，不改变审计保存范围。重定向终端输出会由用户选择的文件保存内容，需按来源许可处理；该选项不授予第三方内容的复制或分享权。

供应商 JSON 响应最多 512 KiB，提取正文最多 80000 个 Unicode 字符；超限拒绝，不静默截断。引文位置对应收到的 Markdown，采用 Unicode 码点、从 0 开始、末端不包含，与网页 HTML 或 JavaScript UTF-16 位置不同。

## 状态如何理解

| 字段或状态 | 含义 |
| --- | --- |
| `acquired` | 收到符合本地契约的非空正文；即使某条引文缺失，读取也可成功，需分别检查 `quote_checks`。 |
| `unavailable` | 请求后遇到限流、鉴权、访问策略、无可提取内容、响应超限或其他错误；不推断目标网站的具体失败原因。 |
| `stopped` | 费用、价格卡或读取策略检查未通过，没有发出请求。 |
| `matched/ambiguous/missing` | 引文精确唯一匹配、重复歧义或未匹配；不是事实核验结论。 |
| `identity_scope=reviewed_requested_url_only` | 审查的是请求地址，未认证返回内容的实际来源。 |
| `final_url/redirect_chain=null` | 当前供应商契约未给最终网址与跳转链；不能自行补成请求网址或“没有跳转”。 |
| `date_applicability=unknown` | 采集时间不是发布日期或当日有效期。 |
| `semantic_support=not_assessed` | 未确认引文是否充分支持主张；否定、范围、例外和断章取义仍需语义核查。 |

`facts_verified=false` 和 `content_origin_verified=false` 始终保留。内容哈希只标识本次收到的文本，不是供应商签名或网页原件认证。

页面级 `semantic_support=not_assessed` 表示没有对全文完成语义判断。规划活动可另提 [预约主张](CLAIMS.md)，取得局部完整段落的有限支持/反证和文字日期报告；它不会把页面整体或来源身份提升成已核实。

## 费用与留痕

复用人民币微元账本，CLI 上限默认500分且不可超过500分。按本轮核对的人民币价格，Fetch 每次成功请求 0.005 元，价格卡到 2026-11-15 有效。请求前预留，成功解析后结算估算；网络、格式或空内容失败时保留 0.005 元预留并标为未知，避免模糊失败后继续消耗。供应商可能不对失败计费，这里是保守预留，实际账单仍为 null。

独立 CLI 是一次单页读取，不是整段规划。规划内的 `read_page` 已通过 Python `read_page(..., ledger=...)` 共用整次规划的5元总账本与来源调用上限，没有为每个工具新建独立额度。手工分别运行独立命令仍是独立操作，不会自动合并为一次规划的总费用报告。

`runtime/evidence.sqlite3` 的 `page_reads` 表只保存运行 ID、已审查网址、正文指纹/长度、获取时间、定位状态、费用和错误码。重复 ID 不覆盖旧记录。默认不落盘正文、标题、输入引文或凭据；这仍不是完整运行重放。没有新增真实网页全文快照授权或保留期限。

规划内读取的最小记录保存在 `planning_runs` 的 `page_reads` 字段，关联父规划 ID；子记录不再附可被重复相加的累计费用，顶层规划总账本为准。默认 JSON/Markdown 不返回完整正文，但生成行程的引文摘录仍会展示，不能将其当作已核实事实或自动归档许可。

退出码：0 为读取成功；2 为停止、不可用或输入错误；3 为自动审计失败。审计失败仍输出已取得的可用元数据，但不能将该命令记为正常成功。

依据：[DeepSeek Search & Fetch](https://api-docs.deepseek.com/guides/search/)、[人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。真实验证见 [本轮开发日志](devlogs/2026-11-08-m2-pages.md)。
