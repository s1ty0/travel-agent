# 受控单 Agent 行程草案

当前是用于对照实验的串行基线：一个 DeepSeek Agent 自行选择只读工具，服务端限制权限、次数和费用，最终对结构化草案做独立校验。不是完整旅行产品，也不是已实现多 Agent。

规划输入现支持可选 `references`，仅明确设置 `allow_model_use=true` 的资料进入模型。程序定位逐字正文并独立检查声明日期；未共享资料和只有链接不能支持正文引用。资料中的指令不能扩展工具权限，规划不自动保存正文。详见 [资料与重放](REFERENCES.md)。

## 本轮能做什么

- 已明确城市的 1～3 天地点安排。当前 `city` 与 `trip.destination` 必须一致；“南京附近”先要求选择具体城市，周边城市发现留待后续实现。
- 只接受未指定交通方式或 `public/mixed` 的草案；当前仅校验步行段，不擅自替换明确的驾车/航班/铁路方案。
- 模型调用 `search_web`、`find_places`、`walking_route`、`submit_plan`。没有订单、支付、升级套餐、发消息、任意 URL 读取或文件写入工具。
- 地点名称、地址与 POI ID 由已返回的地图记录填充，不让模型编写。模型只选择来源 ID 和建议时段。
- 逐日覆盖、活动数量、时间重叠、地点引用、引文片段和相邻地点步行时间由程序检查。每个相邻步行段增加 10 分钟缓冲；这不是对实际通行时间的保证。
- 最终选择的地点 ID 与模型之前查路线的 ID 不一致时，服务端只在剩余请求额度内重新查询正确端点。不沿用其他地点或反方向路线；没有余量时标为未知。
- 费用缺失保持未知，当前不生成精确旅行费用或“预算满足”的结论。营业、预约、住宿、无障碍、跨城交通继续标为待核实。
- 输出 JSON 或 Markdown。仍有未知条件时为 `draft`，已知约束冲突时为 `invalid_plan`，权限、格式或额度阻塞时为 `stopped/needs_input`。

## 本地执行

`.env` 已配置的密钥只供本地读取。用户 2026-11-08 确认服务成本上限 **2 元/次**，高德只用免费额度，耗尽后停止，不自动升级或购买。

```dotenv
AMAP_FREE_QUOTA_ONLY=1
SERVICE_BUDGET_MINOR=200
```

`SERVICE_BUDGET_MINOR` 的单位是人民币分，只能设为 1～200。它与旅行预算完全分开。

```powershell
uv sync --locked --cache-dir .cache/uv
'{"city":"南京","trip":{"destination":"南京","origin":"南京","adults":1,"days":1,"budget":"总预算2000以内","transport_mode":"public","preferences":["博物馆","两个地点，尽量靠近"]}}' | uv run --cache-dir .cache/uv --env-file .env --no-sync travel-agent-plan --live --format markdown
```

省略 `--format markdown` 输出机器可读 JSON。缺少日期等条件允许输出明确草案，不声称生成了正式可执行行程。管道需使用 UTF-8。无 `--live` 不调用服务。当前没有对外的付费规划 HTTP 路由。

## 调用预算怎样控制

| 资源 | 默认限制 | 边界 |
| --- | --- | --- |
| 模型 | 最多 4 次，每次最多输出 1024 tokens | 禁用思考模式，不保存私有思维链；输入含历史和工具 schema，序列化文本最多 48000 UTF-8 字节。 |
| 来源 | 总共最多 5 次，硬上限可配置为不超过 6 次 | 包括服务端最终路线复查；不自动翻页、重试或升级。相同参数在单次运行内复用结果。 |
| 时间 | 默认 90 秒，配置最多 120 秒 | 每步前检查剩余时间，缩短 HTTP 超时；当前 HTTP 读写超时不是可强制中断任意底层连接的绝对任务截止时间。 |
| 金额 | 每次最多 2 元 | 采用本地价格快照和费用预留；不是供应商侧的账单封顶功能。 |

2026-11-08 查阅的 [DeepSeek 官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：Flash 输入缓存未命中高峰价 2 元/百万 tokens，输出高峰价 8 元/百万 tokens；搜索 5 元/千次成功请求。采用高峰、未命中价格作保守估算，不依赖缓存优惠和时段折扣。

请求前按保守输入预留 120000 tokens 与最大输出量预留费用；返回后用实际 token 数按上述高价结算估算。请求文本限制与预留 token 数留有较大余量，但不是供应商 tokenizer 的形式化上界；一旦用量超出预留、缺失或模型计价不匹配，就保留预留并停止后续调用，不能逆转已经产生的上游消费。

价格卡仅允许 `deepseek-flash`，有效期至 2026-11-15。过期或换模型时阻止真实调用，重新核价后更新代码和测试。当前输出 `estimated_upper` 是已知用量的费用上界估算，不是已核对账单；未知费用保留 `reserved_unsettled`，实际账单为 null。微元 `micro_cny` 是百万分之一元，避免小额调用按整分四舍五入而失真。

高德免费模式依赖用户确认的账号配置和供应商拒绝机制。本程序不能读到账户免费额度余额，也不能代替供应商控制台关闭付费回退。收到额度/限流拒绝立即停止，不重试、不换账号、不请求购买。若控制台实际允许自动超额扣费，必须先关闭该设置；本地标志不改变供应商账号策略。

现有独立提取/来源 CLI 保留单次连通测试用途，不经过整套规划账本；整次 2 元控制只在 `travel-agent-plan` 内实现。后续加入 Web、多 Agent、并发、恢复时，账本需要统一持久化和原子认领；当前是单进程串行基线，不宣称可跨多进程共享预算。

## 来源与“可信”的实际程度

引用检查确认“来源存在”和“原句包含在返回摘要或明确共享资料中”，不能证明内容完整、真实、当日有效或确实适用于所选地点。模型改写的事实不标为已核实。规划尚未接入独立 [Fetch 读取器](PAGES.md)，未确认官方身份、营业日期或完成自动事实核验。

所有来源都在结果中列出，带获取时间与状态。搜索调用成功可能仍是空或部分结果；地图同名/别名地点需用户确认。通用需求并不保证每次生成相同地点或相同路线，暂不宣称完整满足全部兴趣和无障碍需求。

运行摘要与已有来源索引一起写入 `runtime/evidence.sqlite3`。保存操作、请求哈希、状态、token 用量、费用估算、价格日期和耗时；不默认保存用户输入、完整对话、模型私有思维链、行程或来源正文。终端输出可能含用户行程，导出时应选择私有位置。

没有自动恢复或重试。未知费用、额度不足、无效工具、重复调用 ID、额外参数和无效 JSON 均停止；有用的已获取来源仍保留。新建运行是新的一次服务预算，不自动把失败运行隐藏后重新计费。
