# ADR-0005：先建受控单 Agent 基线，服务成本与旅行预算分开

日期：2026-11-08。状态：本地 CLI 基线采用；不视为 M2 全部完成或产品发布。

## 已确认的规则

用户指定服务调用费用上限为 **2 元/次**。高德使用免费配额，耗尽即停止；后续确有需要再另行购买，不授权自动升级或充值。这些约束独立于“旅行预算 2000 元”等用户行程条件。

## 决定与理由

- 使用 DeepSeek 正常工具调用回合，模型返回工具请求，服务端校验白名单和参数后执行，再把匹配调用 ID 的结果回传。没有把服务端虚构的工具请求插入历史。
- 单 Agent 串行基线先实现，不提前引入 LangGraph。M3 再用相同来源、模型和费用条件比较串行、并行工具与多 Agent。
- 最终计划采用窄的结构：地点来源 ID、建议日期序号/时段、活动类型、可选的逐字摘要引用。服务端补地点名和地址，避免自由文本绕过价格/来源边界。
- 最终路线按实际选择的来源 ID 校验；模型查过某个同名地点的路线不代表最终路线已查。
- 调用前保守预留微元费用，用量已知后按高峰未命中单价估算；用量/价格不明停止，不把 null 记成零。价格卡过期后禁止调用，不静默沿用旧价格。
- 先保留搜索、地点、步行和提交草案四个工具；不提供购买、套餐升级或任意代码/URL 工具。外部内容不能扩展工具集。
- 只输出草案及独立规则检查。来源定位与摘要引用通过不等于营业、票务或预算事实已经核实。

## 代价和后续

当前每次运行最多 4 个模型回合、5 次来源请求，可能不足以覆盖复杂需求；停止并解释缺口优于隐藏重试。仅支持具体城市 1～3 天，周边城市发现另做。

预算预留不是供应商账单硬限额；token 估算、价格变动及高德实际账户付费回退都有外部依赖。正式 Web/多 Agent 执行前，需要持久化原子预算、价格/配额监控、身份隔离、恢复和真实账单对账。本地标志不改变供应商控制台政策。
