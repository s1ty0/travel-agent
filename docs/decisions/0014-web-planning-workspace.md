# ADR-0014 网页提问和规划工作台

日期 2026-11-10。状态采用，本机可试用，公开部署待验收。

用户需要通过浏览器询问旅行，并把网页作为正式产品的入口。提前实现一条可用链路，复用现有 FastAPI 规划引擎。原始提问与显式确认条件分开，城市和总预算直接交由后端验证。默认示例仅填入文本，点击确认才创建真实任务。

采用 Next.js App Router、React 和 TypeScript。当前表单和响应式布局使用原生控件与 CSS。锁文件采用 npm，适配现有 Node.js 环境。前端静态、组件与浏览器测试进入 CI。Biome 与 Prettier 组合替换初次试装的 ESLint 依赖链，最终前端依赖审计无已知告警。

本机使用 Next.js 同源代理、短期会话和 FastAPI 单进程任务。代理限制回环地址、来源、路径及请求大小，服务间令牌留在服务器。任务在内存中有界暂存，重复请求 ID 复用同一任务。此边界只支持本机开发，需要生产身份、持久化与分布式配额后才能对外开放。此决定细化 PLAN 第 2.6 节早期栈选择。

详见 [网页使用与上线门禁](../WEB.md)。
