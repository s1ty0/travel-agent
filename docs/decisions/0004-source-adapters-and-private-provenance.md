# ADR-0004：来源层独立，最小留痕与事实核验分开

日期：2026-11-08。状态：采用于 M2。

1. DeepSeek 结构化搜索与高德地点/步行路线独立于模型提取，供多个 Agent 复用；不按平台重复建 Agent。
2. 先使用单请求、显式翻页、无自动重试的只读来源 CLI，避免未完成运行级预算前扩大消耗。
3. 搜索摘要、地点记录和路线估算分别标记，接口成功不等于旅游事实核验。结果有缺口就显示部分结果，不用模型补造。
4. SQLite 保存查询指纹、来源定位、状态和结果哈希，不默认归档正文、用户查询、坐标、密钥和响应全文。需要历史重放时另立许可与保存策略。
5. 模拟协议、真实连通和内容准确性是三层验收；没有账号或权限时明确记为未验收，不妨碍其他独立模块继续开发。
6. 坐标系、米/秒单位、步行方式显式保留。周边地点查询不替代周边旅游目的地发现。

代价：最小索引不能独立恢复原文或完整重放接口；来源链接过滤也不证明站点内容、来源独立性或时效。正文核验、任务预算和完整规划仍需后续实现。

SQLite 使用事务并显式关闭连接，重复运行 ID 不覆盖历史；并不声称它是能抵抗本地数据库写入者的不可篡改审计系统。
