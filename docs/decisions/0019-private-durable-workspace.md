# ADR-0019 私有会话、持久任务与局部修改

日期2026-11-11。状态采用，替代ADR-0014仅内存30分钟的任务存储。范围是本机可演示MVP，不是已部署的公网账户系统。

采用SQLite WAL与事务保存任务、输入、完成方案、来源必要片段、父子版本及最小用量快照，7天到期清理，可按旅行删除全部版本。保留30天的请求指纹墓碑与最小配额记录，防止删除后重复请求意外再次扣费；删除不承诺清理操作系统备份或物理介质的全部痕迹。数据库仅在被忽略的本地runtime目录，不进入Git或安装包。不保存Fetch整页或私有思维链。

浏览器使用256位随机HttpOnly、SameSite=Strict会话凭证，服务器只持久保存其SHA-256。所有读取、版本、取消、删除和条件继承都按资源所有者校验；异会话返回404。Cookie保留7天，清理Cookie会失去访问。它提供匿名私有工作区能力，不冒充实名登录、多设备账户恢复或生产身份认证。桥接令牌仍只在服务端，重启时轮换不影响同会话读取已存方案。

事务创建确保请求ID/输入指纹幂等，每会话最多1个活跃任务、全局2个；滚动24小时每会话20次、全局100次，删除不能重置。独立工作进程原子认领队列任务，并以60秒租约记录阶段与费用预留快照。中断任务标记interrupted，费用状态保守未知，不重放已开始的付费工作；已排队但未开始的任务可被工作进程认领。取消只阻止后续调用，已发出请求仍可能产生费用，已有结果和费用继续保留。

网页增加历史、版本差异、进度、取消及删除，修改输入框在生成后清空，已有偏好与明确条件由服务端和原版本保留。当前支持明确的单日结束时间、少走路、移除唯一地点及预算修改。局部编排重用已取得证据，不调用模型；需要新相邻路线时才进行有界地图查询，不能保证所有修改零查询。不涉及的日期和原停留时长保留。含糊单日修改要求补充，不把“第二天”错误解释成全程两天。

本地启动同时运行Next.js、FastAPI和独立Python worker。Windows停止前先验证仓库路径，再按快照回收完整进程树；测试启动器使用无捕获管道的子进程，避免后台句柄导致等待不结束。SQLite适用于当前有界本机演示，多主机生产存储、真正账户、HTTPS、运维和预发布仍独立验收。
