# ADR-0006：用户正文定位与独立授权

日期：2026-11-08。状态：采用于 M2，不宣称完整事实核验完成。

搜索摘要引用不能替代原文。用户资料也必须分清正文、摘要、链接，且不能默认上传或保存私人信息。

1. 接收粘贴正文、摘要或链接；只传链接保持 `link_only`，不虚构获取成功/失败。
2. 模型共享与快照保存独立授权，默认关闭；规划运行不自动镜像正文。
3. 引文返回精确码点偏移、行号与哈希，重复引文标歧义，日期另行判断，不认定现实事实真实。
4. 授权快照可离线重放与删除，重放校验大小、哈希、版本与权限；本地明文，不冒称不可伪造签名。
5. 接入单 Agent，但工具白名单和费用限制不变；新增本地无状态检查 API，不增加付费/购买 HTTP 路由。
6. 10 条合成证据样例作为固定回归。它们已用于开发，不当作独立保留集。

本轮不自动调用 Fetch、不绕过访问限制，不将粘贴内容标成官方抓取全文。来源身份、现实真实性、语义充分性和冲突需后续独立核验。

快照只重放已保存资料的定位，不重放整个模型和真实 API 链路。多用户隔离、加密、保留期限、真实响应保存许可和独立保留评测仍为后续任务。
