# ADR-0022：公网真实规划与开放地图快照

日期：2026-11-11。状态：首发已实施。

## 背景与替代关系

用户要求最终 Vercel 公网入口，不接受演示行程。此前受保护的合成 Preview 只完成云端链路验收，不能作为真实旅游规划交付。本决定扩展 ADR-0021 的本机交付范围；历史测试与失败记录保留。

高德账号的公开展示与留存权限尚未确认。现有免费配额不能证明这些权限。小红书按用户决定从首发跳过，不接未获授权的搜索接口。

## 决定

- 生产前后端均拒绝演示配置与历史；供应商失败时显示错误和已知缺口，不回退合成结果。
- 首发地图使用2026-11-11从 OpenStreetMap 官方 API 获取的真实小范围快照，覆盖杭州西湖东岸与苏州古城。派生地点及路网、构建脚本和 ODbL 许可随仓库提供，网页与导出展示贡献者署名。
- 规划时本地读取快照，不对 OSM 公共服务发实时规划请求。步行路线沿快照可达路网计算，短距离接驳受限；未知路线仍标未知，时间明确为估算。
- DeepSeek 模型与搜索实时调用。生产 Neon、加密 Key 和桥接凭据与预览独立。管理员试用按会话3次、同网络滚动24小时3次、全站累计6次限制；后者是首发保守配置，可显式调整，不自动购买额度。
- 发布前运行离线全量、真实 PostgreSQL、六组 CI 与候选真实规划；提升后用无需登录的浏览器验收真实首稿、手机布局、导出与刷新恢复。

## 代价与后续

范围暂限两个城区，不表示覆盖两市全部范围。地图快照不是实时营业和可进入性验证；门店可能变化，名称或地址字段可能缺失。票价、预约、酒店与城际交通供给未接齐，不能据此承诺整趟旅行可订或已满足总预算。后续按真实反馈扩充数据、补独立事实核验和运维，不将当前小样本视为稳定质量证明。
