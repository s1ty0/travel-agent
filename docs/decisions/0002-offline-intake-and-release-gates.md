# ADR-0002：离线领域层先行，分层测试后再上线

日期：2026-11-08。状态：已采用于 M1；不替代 ADR-0001 的后续编排方案。

用户要求正式上线前运行冒烟、回归及全量测试，通过后才上线。将该要求写入长期记忆和 [测试门禁](../TESTING.md)，区分阶段完成和发布放行。

M1 使用 Python、Pydantic 和 FastAPI；uv 创建项目隔离环境并锁定依赖。先解析专用字段，不声称已经理解完整自由对话。未知地点实体保持未核实；“南京附近”不推导出发地。

预算按整数分和区间计算。消费人数、天数、房间、晚数、数量、税费和预备金明确建模。总预算与每人/每天预算分别归一化，口径或费用缺失返回未知。已知最低费用已超预算时，即使其他费用未知也能报告超支。

当前只提供本地、无账户、无外部来源的 API，不用于直接公开部署。编排、账户、身份认证、数据隔离和交易另行实现。模型/搜索的服务调用成本尚不在本轮旅行费用模型内。

测试使用 20 条固定回归样例、业务边界断言、真实本地 HTTP 启动和 CLI 子进程。统一入口失败即停止；本地原始报告不进入 Public 仓库。

安装后的 Starlette 对 httpx 的兼容路径给出弃用告警。查阅本地已安装的 `starlette/testclient.py` 后改用其首选 httpx2 测试依赖，不屏蔽警告；完整依赖版本见 `uv.lock`。依赖管理依据官方 [Pydantic 模型文档](https://docs.pydantic.dev/latest/concepts/models/) 与 [FastAPI 测试文档](https://fastapi.tiangolo.com/tutorial/testing/)，实际兼容性以本次运行结果为准。
