# ADR-0017 简历项目交付范围与5元服务预算

日期2026-11-11。状态采用。用户明确授权独立开发与测试，阶段完成后简报，持续到产出可用于AI全栈简历的项目。服务预算由2元提高为5元/次，替代ADR-0005中的旧上限；历史实验记录保留原额度。

交付边界为可复现、可演示的国内单城1～3天只读旅游规划MVP，包含首稿、来源、确定性时间/交通检查、用餐候选、局部修改、私有任务与版本、真实并行研究对照、评测及简历材料。采用现有Next.js/TypeScript与FastAPI/Pydantic，不为展示重写技术栈。

每次规划含解析、各Agent、查询、整合与有限修正，共用人民币微元账本，最大500分；并发预留必须原子执行，未明用量保留预留并停止后续消耗。模型仍只用DeepSeek；高德只用免费额度，耗尽停止。新增引擎可设置单独的有限模型/查询上限并明确记录，不能凭5元默认为无限重试。旧单Agent基线及冻结验收保留原调用次数，显式2元测试仍可执行。

简历交付优先提供一键本地演示和Docker部署文件。正式公网部署仍受既有完整门禁约束，不把本机、合成测试或试验结果标成已上线、事实认证或商业可执行。平台授权、真实票务/酒店报价、交易及原生App不作为本轮完成条件。

阶段依次为：S1可用规划及确定性时间求解；S2持久任务、版本、会话隔离与局部修改；S3并行研究及公平对照；S4一键演示、架构、评测、简历材料和最终测试。每个阶段保存代码、决定、脱敏结果及未解决事项。现有规划覆盖率不代替真实效果评测，生成失败不能通过重试筛选或填充未知来伪装成功。

API结构化生成沿用[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。2026-11-11再次核对[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，Flash高峰未命中输入2元/百万token、输出8元/百万token，Search/Fetch为5元/千次成功调用，与原价格卡一致。价格有效期与未知用量停止规则保持生效。
