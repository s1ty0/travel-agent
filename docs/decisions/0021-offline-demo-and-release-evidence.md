# ADR-0021：明确演示模式与发布证据

日期2026-11-11，状态采用。补充ADR-0017的一键交付，延续ADR-0019私有工作区与ADR-0020对照协议。

默认本机脚本启动合成演示，真实调用必须显式`-Live`。演示不读取根目录`.env`，使用明确的合成模型/来源传输层，所有结果、来源和导出可见标记，真实调用数与费用为0。真实故障不自动切到演示；两种模式的历史证据不可混用。

新增10秒独立租约心跳，避免合法长请求无进度时被60秒失联检查误判。禁去地点同时绑定来源ID与名称，适用于局部修改、重新研究及最终校验；模型换名字也不能绕过。当前替换命令仅移除并提示另选，不编造新来源。

发布验收10例首次在实现完成后执行，一次离线三策略和一次真实模型/合成来源标准策略，结果及费用按原预期保留，不修改预期、不付费筛选成功。使用后进入30例×三策略回归；公开报告只保存脱敏指标和指纹，原始输入/来源/会话在忽略目录。

PowerShell三进程路径是本机交付验收对象。提供Docker参考文件但主机无Docker，不声称构建运行通过。简历材料只写实际能力和条件化实测，公网部署、交易、身份与独立事实认证继续后续开发。

用户实际试用入口以真实模式启动。演示默认使用独立数据库，避免切换后工作进程认领另一模式的任务。原数据库里的合成结果由网页根据标记跳过，防止旧草案被误用为真实规划的起点。
