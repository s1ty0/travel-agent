# ADR-0010：预约资料的一致性与候选关联

日期：2026-11-09。状态：采用于 M2，承接 ADR-0009，不改变原有未认证边界。

1. 每个预约主题比较本次全部可用且获准共享的资料，不只看模型选中的引用，不新增来源调用。
2. 单条引用是否成立与多份资料是否一致分开。其他文本支持不能修复伪造引用；不明真假来源冲突不直接推成现实硬约束。
3. 复用完整段落有限语法及反驳保护，区分同日文字冲突、日期不足与不同文字时段，不以采集顺序或多数票选赢家。
4. 按相同规范文本、声明网址和主机标记候选关联，保留全部版本。这些线索不认证作者或发布机构，候选组数不是独立来源数。
5. 独立证明计数保持 0，事实认证保持 false。更多模型、Agent 或引用不自动提升可信度。
6. 来源版本与规则设上限；截限或同 ID 多版本需提示未完整完成，不静默覆盖或声称无冲突。
7. 输出必要的日期、位置与指纹；最小审计只留版本、指纹和计数，不保存原文、主题和网址。

首版没有近似改写去重、转载谱系、注册域/作者认证或全文语义理解。扩展需真实反例与独立评测，不能用引用数量代替独立证明。
