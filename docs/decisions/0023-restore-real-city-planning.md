# ADR-0023：恢复实时地图与用户决定的试用额度

日期：2026-11-11。状态：用户已明确要求，候选已实现。

## 用户纠正与替代关系

用户否决助手将产品擅自缩为杭州西湖东岸和苏州古城。产品目标是帮助人进行旅游规划，不是两个城区的受限展示。涉及支持范围、核心功能、数据源和使用限制的变化，必须先说明影响并征得用户确认，再实施。

本决定替代 ADR-0022 中强制将公网地图改为 OSM 两城区快照的决定。真实模式禁止合成回退、私有任务、费用控制和来源留痕继续保留。

## 已明确授权的变更

- 公网恢复已有 DeepSeek 模型、搜索及高德地点、餐饮周边、步行路线适配器。不设杭州/苏州白名单；是否有可用地点、路线和条件仍按真实返回判断。
- 高德继续使用用户提供并明确指示使用的服务端 Key。免费额度耗尽即停，不自动购买、不重试扣费请求。不将用户的使用指示写成已取得第三方许可的核实结论。
- 用户要求将试用从3次提高为10次：每匿名会话最多10次，同网络滚动24小时最多10次，保持换 Cookie 防刷。
- 用户另行明确选择全站累计10次，按每次5元服务上界估算最多50元。既有消耗不重置；自带 DeepSeek Key 不占管理员试用。
- OSM 快照仅保留为可显式选择的适配器和回归资料，不再由 Vercel 环境隐式强制开启。

## 适用边界

本轮修复撤销擅自施加的城市限制。原有单城1～3天、步行估算、营业/预约/完整旅行报价缺口仍是当前实现范围，后续按用户的旅游助手目标补齐；不删除真实失败提示来冒充所有条件已满足。
