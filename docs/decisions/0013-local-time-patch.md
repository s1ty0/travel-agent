# ADR-0013：纯时间修正采用局部补丁

日期：2026-11-10。状态：采用。替代 ADR-0012 中纯时间模式重新提交完整活动的机制；保留其范围约束及数量/逐日覆盖模式，不改变默认零修正。

ADR-0012 已能拒绝范围漂移，但真实 v2 重叠修正仍越界失败。仅用提示要求模型完整复制所有活动字段，增加了重写和遗漏的机会。改为模型提交原版本指纹、活动索引和新开始时间，由程序保留原活动及停留时长，派生结束时间。

补丁绑定原结构化提交 SHA-256，索引按原数组顺序定位，不能按地点 ID 合并重复访问。每份 1～9 项、索引唯一、严格整数分钟，超出当天、版本或索引不匹配时拒绝整份补丁；原方案不变。模型没有删除、缩短、改引文或改类型的字段权限。

仅纯时间失败提供新工具，数量和逐日覆盖仍用原完整提交，保持各自已有范围规则。补丁应用后仍执行完整校验及准确路线核查，同一预算、次数和截止时间，失败不自动修正第二次。

受控实验升为 `hybrid-repair-v3-time-patch`，旧报告保留，不修改冻结用例字节与预期；脚本供应商按实际开放协议返回对应动作。一次真实候选批次 3/3 通过，只说明三个已知合成上下文的本次行为，不宣称显著改善、稳定性或完整旅行质量。
