# ADR-0012：限制修正范围，分开真实模型与模拟上下文

日期：2026-11-09。状态：采用。补充 ADR-0011 的一次修正规则，不改变默认零修正、原账本或调用上限。

时间校验通过不能证明修正合理。模型可能通过删活动、缩短停留、改类型或删除依据避开冲突。因此纯时间修正冻结非时间字段及停留时长，仅移动时段；数量修正额外允许删除原活动，但不能新增、复制或改类型。逐日覆盖需重建活动，作为明确例外，继续执行完整校验。

约束由服务端比较活动签名多重集合执行，签名包含所有非起止时间字段和持续分钟数。纯时间模式要求相等，数量模式要求是原集合的子多重集合；保留重复计数，不能仅比较地点集合。违规后不追加路线查询，最终方案为 invalid_plan，不提供第二次修正。

真实模型实验使用合成初始冲突与来源，仅开放一个真实修正回合。这样可确定触发修正，并准确区分模型行为和供应商数据；代价是不能评价真实端到端旅行质量。报告和文档必须明确此边界。离线模式继续供 CI 使用，不引入密钥或付费调用。

实验失败不通过追加尝试抹掉。修改实验驱动或规则必须另记版本、原因和新报告；旧报告不覆盖。当前一次 v2 批次生成修正 2/3，仍不满足真实修正整体验收；保留默认关闭并把失败列入后续工作。
