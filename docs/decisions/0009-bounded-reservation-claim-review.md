# ADR-0009：预约主张分层核查

日期：2026-11-09。状态：采用于 M2 首版预约主张。承接 ADR-0008 的已读正文，不替代独立官方身份认证或完整事实核验。

## 决定

1. 模型提出结构化候选主张，程序核查，首版只支持“需要/无需预约”。不借另一次模型认同认证现实事实，也不增加付费核查回合。
2. 来源身份、逐字定位、完整段落的有限语义、地点名称和出行日期分别报告。当前身份独立证据不足时始终未认证，不把网站自称、政府域名后缀或用户声明当成归属证明。
3. 精确语法只处理明确主体和预约要求。不能解释的条件、例外和复杂文本保留不足；可识别反驳和相反规则需复核，不丢掉限定词。这里是有限文本关系，不是通用语言理解。
4. 日期只来自同一规则段落的明确双边年份范围，不能从采集时间、URL、发布日期或用户声明推成有效期。
5. 缺失/歧义引用、明确相反文本或范围不符拒绝的是该份依据，并使方案校验失败；不能将它扩大为“现实规则一定相反”。身份或解释不足保留待核实，不自动认证。
6. 主张及核查指纹绑定内容版本、日期、地点和规则版本。最小审计不保存主张原句、主题名或未知模型来源 ID。离线检查接口不触发共享、保存或网络。

## 取舍

首版覆盖窄，但判断边界可检查，能拦截具体证据误用。规则版本 `reservation-rule-v1` 的宽泛提示词检测在真实联调中过严，已由 `v1.1` 的完整反驳语句检测替代；旧报告保留，不冒充最终结果。

当前没有 `facts_verified=true` 的放行路径，因为最终内容归属、日期和来源权威仍缺独立闭环。后续扩展新的事实类型和句式时，需增加明确语义、真实反例和独立评测；不能仅扩大正则匹配就宣称完成事实核验。
