# 行迹网页工作台

网页是正式网站的首条开发链路。用户发送自然语言想法后，先生成带假设的首稿，再补充精确条件继续完善。页面调用现有 DeepSeek、高德和行程校验流程，显示逐日安排、来源、待核实事项及可下载的 Markdown 草案。

## 本地运行

需要 Python 3.11+、uv 和 Node.js 24。在仓库根目录执行：

```powershell
uv sync --locked
npm --prefix web ci
npm --prefix web run build
powershell -ExecutionPolicy Bypass -File scripts/start-web.ps1 -Live -Production
```

打开 <http://127.0.0.1:3000>。选择「南京 · 博物馆慢游」填入想法，再点击发送箭头生成首稿。也可直接输入「想去南京玩一天，预算2000以内」。有首稿后可继续发送「预算改为3000以内」等短句，或在条件栏修改后点击更新。

模型提取目的地、预算、出发地、原文天数和成人人数。非空候选必须逐字来自本次输入。天数缺失时暂按 1 天并显示假设，预算与人数缺失时继续未知。没有目的城市或输入范围超出当前单城 1～3 天能力时，返回补充条件提示。复杂日期、周边目的地选择与复杂条件语义继续由后续版本完善。

`-Live` 使用现有被忽略的根目录 `.env`。本机开发时省略 `-Production` 启动热更新。省略 `-Live` 可检查页面，但不能提交真实规划。脚本检查端口占用和前后端连通性。服务、进程记录和诊断日志在 `artifacts/web/` 对应的忽略目录中留痕，监听地址为本机 3000 与 8000。

## 当前能力

- 已选国内城市、1～3 天，预算支持单值、上限及范围并保留原口径。出发日期、人数、预算与出发地可补充。全程景点上限与一次冲突修正可在更多条件里调整。
- 行程按天展示。默认每日09:00～20:00，可在更多条件中修改；短句续写保留已选范围。午餐、晚餐、转场、休息与晚间/返程显示为待落实时段，具体餐厅和夜游地点仍待查询。整天缺失、缺餐和交通冲突明确提示，补充留白不等于安排通过。
- 景点总上限默认自动安排，可显式限量；网页默认允许一次原额度内修正，可关闭。收尾和修正共用4次模型、5次来源和2元上限，不保证模型一定修正成功。CLI仍默认零修正。
- 来源区显示搜索摘要、地图地点、路线估算和获取时间。检查区区分确定冲突与未知，旅行费用未知时不会显示为零或预算通过。
- 规划最多 2 元服务调用上限，与旅行预算分开。高德沿用已确认的免费模式，额度耗尽停止。页面发起真实任务时使用原有模型、来源、超时和预算规则。
- 想法提取与规划共用原账本、模型总次数和耗时。来源用尽后只整理已有资料，不再执行新增查询。必要资料缺失时保留缺口。修改条件或补充新想法会创建一次新规划，每次独立受 2 元上限约束。
- 单日任务若模型用满回合仍未提交，网页可根据已有搜索和地点记录起草轻量初稿，明确注明程序起草、09:00 停留60分钟及偏好/用途待核实。本版程序起草仅覆盖单日；缺少必要来源、供应商故障和费用未知仍可能停止。已经提交的无效方案继续显示冲突。
- 补充短句会读取所属会话上一任务的结构化条件，新明确字段覆盖原值，其余沿用。更新期间保留上一版，完成后可切换查看。上一版显示只在本页内存中，刷新仅恢复当前任务。
- 刷新可重新读取同一临时任务。页面以相同请求 ID 找回可能已接收的提交。单进程同一时刻只接一个任务，任务结果可读 30 分钟或直到进程重启。用户可以主动导出 Markdown。关闭页面只停止观察。
- 预约、下单和支付由后续人工审批阶段设计。周边候选发现、票务与酒店查询、完整费用，以及按对话连续编辑仍待开发。

## 本机接入与上线门禁

Next.js 服务端通过固定回环地址和路由白名单访问 FastAPI，启动脚本生成一次服务间凭据。浏览器使用同源 HttpOnly 会话，任务读取检查会话归属。访问中的任务在内存中暂存，已有最小审计保存在忽略目录 `runtime/web-audit.sqlite3`。浏览器会话存储只记录任务 ID。生产需要正式身份与逐资源授权、持久任务和取消、跨进程幂等与配额、数据删除、HTTPS、故障恢复和真实预发布验收。

前端采用 Next.js App Router、React、TypeScript、npm 锁文件与原生 CSS。Biome 和 Prettier 检查代码，Vitest 检查组件和同源代理，Playwright 在 CI 检查桌面与手机视口。浏览器测试只注入合成任务，真实联调结果另行记录。[Next.js 安装文档](https://nextjs.org/docs/app/getting-started/installation)

```powershell
npm --prefix web run lint
npm --prefix web run format:check
npm --prefix web run check
npm --prefix web test
npm --prefix web run build
uv run --no-sync python scripts/check.py
```
