# 网页工作台

当前为Next.js/React/TypeScript与FastAPI/Pydantic组成的本机只读规划MVP。先从自然语言生成首稿，再通过短句或条件栏完善。网页是后续网站的代码基础；当前未公网部署，不代表已满足生产身份、运维和事实核验门禁。

## 运行与交互

无密钥演示运行`powershell -ExecutionPolicy Bypass -File scripts/demo.ps1`。已有构建可加`-SkipBuild`。明确真实调用使用`powershell -ExecutionPolicy Bypass -File scripts/start-web.ps1 -Live -Production`，本机`.env`配置见[演示说明](DEMO.md)。省略`-Live`默认合成演示，不读取根目录`.env`；省略`-Production`使用开发网页服务。

页眉显示当前模式。真实规划通过 DeepSeek 搜索与高德地图生成已选城市1～3天的草案，周边城市发现待接入。合成演示支持南京、杭州、上海1～3天。默认使用各自的任务数据库，切换到真实规划时会忽略此前打开的合成结果。缺预算、人数或日期可先出草案，天数缺失暂按1天。每日09:00～20:00、步行上限90分钟可修改。

来源先行引擎取得搜索、城市地点与餐饮候选，模型选择ID和天数，程序安排附近餐厅、步行与缓冲。支持标准联合、并行查询和专精并行，默认标准；最多8次模型、20次来源、180秒，共享5元估算账本。免费地图额度故障停止，不重试或扩容。旧基线可设`TRAVEL_PLANNER_ENGINE=baseline`，4次模型/5次来源，可选一次受限修正；演示始终使用来源先行引擎。

时间线含每天景点、午晚餐、转场、休息与晚间/返程留白。留白不是已查询的夜游项目或已确认返程；超出时间、整天缺失、未知路线和未知费用继续展示缺口。规则满足不证明营业、预约或票务真实，旅行总费用未知时不计作零。

## 私有历史与局部修改

浏览器使用匿名私有能力凭据，SQLite保存必要输入、来源片段与版本7天；删除Cookie后无法找回。历史可切换版本、查看增删及时间变化、导出Markdown、两步确认删除全部版本。当前不是注册账户或跨设备恢复。

明确支持“第二天下午五点结束”“第二天少走路”“去掉行程中的完整地点名”“预算改为3000以内”。少走路暂按45分钟，可调整。程序复用证据，不调用研究模型；保留其他日期与原活动时长，新相邻端点需要时只补查对应路线，不能承诺零查询。“换掉”目前仅移除并提示另选，不自动编造替代地点；含糊单日修改停止并提示补充。名字和来源ID同时绑定排除，重新研究仍执行。

## 任务、权限与恢复

启动脚本运行网页、API和独立worker，监听本机3000/8000。Next.js服务端通过固定回环白名单代理API，服务间凭据不进入浏览器；浏览器HttpOnly、SameSite=Strict会话在每次读取/取消/删除检查归属。输入上限、同源检查及错误脱敏另设门禁。

任务事务幂等与独占认领，10秒心跳续60秒租约。完成任务重启后可读取；失联任务标中断，不自动重放可能收费的请求。同请求删除后30天墓碑拒绝重新生成。每会话/全局活跃上限1/2，滚动24小时20/100次，最多32版。取消只停止后续工作，已发出的调用可能继续计费；关闭网页不取消任务。

停止运行`powershell -ExecutionPolicy Bypass -File scripts/stop-web.ps1`，脚本验证工作区后回收进程树。诊断日志在忽略的`artifacts/web/`，私有任务与最小审计在`runtime/`。数据库未加密，主机管理员可访问；生产仍需正式身份、HTTPS、备份、监控、全局账户防滥用与真实预发布验收。
