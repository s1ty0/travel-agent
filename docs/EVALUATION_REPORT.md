# 评测与交付证据

日期：2026-11-11。结论：形成可演示、可复现的本机只读MVP；不是独立旅行质量认证或公网生产验收。

## 数据、协议与复现

冻结数据`tests/fixtures/product_evaluation_v1.json`包含20条开发、10条发布验收，共30个项目自编合成场景。LF规范哈希为`3f8e5e6f0786f09754f219f2b50b87756c242c5471b8e39ece67cfb472b3652d`。开发用例已用于调试，发布验收首次在S4运行，无修改预期或付费筛选重试；使用后全部进入回归，不再称未见保留集。

评价由程序执行：预期状态、请求天数覆盖、地点来源ID、确定冲突、事实未认证。无解、排除全部、缺必去与超数量等预期拒绝单独计数；未知路线/坐标可以保留草案与缺口，不能读成交通可行已认证。合成契约不评判真实旅行体验，也不证明价格/营业真实。

默认不联网，重放命令：

```powershell
uv run --no-sync python scripts/evaluate_product.py --split development --replace-offline-report --output artifacts/evaluation/development-replay.json
uv run --no-sync python scripts/evaluate_product.py --split acceptance --replace-offline-report --output artifacts/evaluation/acceptance-replay.json
uv run --no-sync python scripts/check.py
```

真实模型必须显式`--live`和最多10例，真实来源另需`--live-sources`且最多3例、已确认免费配额。报告已存在即拒绝，不覆盖或自动重试付费批次；上述覆盖参数仅允许离线。私有原报告不上传，公开的[脱敏指标](evaluation/release-2026-11-11.json)只保留协议、指纹、聚合和逐例状态。

## 发布验收：一次真实模型批次

10例，每例标准策略一次；固定合成来源，9次实际DeepSeek调用、0次实际来源调用（完全排除案例在模型前停止）。10/10结果符合工程预期：6份草案、4例正确拒绝，无无效研究ID、程序补齐或研究失败。模型费用上界估算合计0.048764元，实际账单未对账。模型前拒绝没有模型费；模拟来源账本费用不能当实际来源费。不是10份真实旅行成功。

同一10例×三策略的纯离线验收各10/10，均6草案、4拒绝。随后30例×三策略进入自动回归。没有把模拟运行耗时当实际模型或真实端到端速度。

## S3三策略对照

同3个正常开发案例、固定合成来源、同模型，总共12次实际DeepSeek、0次实际来源请求；每案例/策略只运行一次。来源模拟20毫秒，联合输出最多2048 token，专精1536+512；专精输入重复，费用不相等。

| 策略 | 草案 | 中位耗时 | 模型费用估算合计 | 专精分支重叠 |
| --- | --- | --- | --- | --- |
| 串行工具、联合研究 | 3/3 | 1704毫秒 | 0.016996元 | 不适用 |
| 并行工具、联合研究 | 3/3 | 1796毫秒 | 0.017500元 | 不适用 |
