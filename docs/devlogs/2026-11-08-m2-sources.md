# 2026-11-08：搜索、地图与最小来源索引

## 已实现

- DeepSeek 结构化搜索；高德指定城市地点、坐标周边地点及步行路线。

## 实际发现与修正

第一次全量测试出现 SQLite 连接未关闭的 ResourceWarning。事务上下文只管理提交/回滚，并不替代关闭连接；已使用显式关闭上下文修复生产代码及测试。以资源警告为错误重跑来源测试通过，并将资源泄漏和未处理析构警告加入默认失败条件。

第一次真实搜索按初版链接规则接收 3 条、留下 2 条并标记部分结果。观察到带访客 token 参数的来源链接后，收紧过滤以拒绝 `*token` 参数，增加对应离线回归，并再做一次真实验证。未把第三方 token 链接或完整正文写入公开日志/仓库；早期私有来源索引仍是当时规则下的原始事件，不冒充当前过滤结果。

最终真实搜索接收 3 条，保留 1 条有效来源，2 条被过滤，返回 `partial`；不会凑满条数或让模型补来源。来源摘要仍标记未核实，没有确认南京博物院当前预约或营业规则。

用户在本轮提供高德 Web 服务 Key，已仅保存本地 `.env`。先用地点查询返回的真实坐标作为中心查周边，再用两个真实返回的地点坐标查步行路线，没有硬编码演示坐标冒充实际查询。
