# 2026-11-08：用户资料、引文定位与授权快照

## 本次交付

继续 M2 的证据闭环，新增用户资料输入、离线引文定位、独立授权快照与单 Agent 共享资料引用。一次最多 5 份资料，每份正文最多 8000 个 Unicode 字符；只提供链接时保持 `link_only`，不自动获取网页。

模型共享与本地保存各自授权，均默认关闭。规划提示始终先排除完整 `references` 字段，只加入明确共享的资料；允许快照不等于允许送模型，规划也不自动保存正文。新增 CLI 可检查、保存、离线重放和按 ID 删除；本地无状态 API 只检查，不存正文、不联网。

引文返回精确码点区间、行号、正文哈希和声明日期状态。缺失、重复歧义、未知来源或只有链接均不通过正文引用检查。正文匹配只证明文本存在，始终保留 `facts_verified=false`。资料中的购买或升级指令不能扩大工具白名单。

快照在忽略目录本地明文保存，校验大小、版本、文件/正文哈希和资料 ID，拒绝路径穿越，不覆盖已有文件。哈希不是防篡改签名；当前没有多用户隔离、加密或自动保留期限，不能直接作为线上资料库。

设计依据和使用方法见 [ADR-0006](../decisions/0006-user-references-and-offline-evidence.md)、[REFERENCES.md](../REFERENCES.md)。核对了 DeepSeek 官方搜索/Fetch 文档，但本轮没有接入 Fetch、抓取受限平台或保存真实 API 全文。

## 离线验证与修正

新增 10 条合成证据重放回归，覆盖精确/缺失/重复、Unicode、多行、摘要、链接、过期/未来日期与恶意指令。它们已用于开发，不当作独立保留集。另测独立授权、未共享资料不进提示、伪造哈希/版本、快照上限、删除、CLI/API 无网络和模型工具越权。

首次测试发现 Unicode 样例把 JavaScript UTF-16 偏移误作码点偏移：`🧳南京：按日开放。` 中引文起点应为 4，而非 5。修正测试预期，没有放宽实现。后续文档明确偏移单位，前端需转换。

本地统一入口最终通过：静态、格式、依赖一致性、冒烟 9 项、固定回归 30 项、全量 259 项；子集不重复计数。语句与分支合并覆盖率 97.97%，无测试警告。原始报告保存在被忽略的 `artifacts/qa/`。
