# 公网真实规划候选

用户要求公网正式域名，演示只在本机和自动测试使用。此前受保护的合成网页已撤下。Vercel 网页代理和后端都拒绝合成配置与旧合成结果。真实服务停用时显示具体错误，不生成假行程。

当前高德账号没有公开使用确认。公网改为 DeepSeek 搜索与 OpenStreetMap 数据。2026-11-11 从官方地图 API 获取杭州西湖东岸和苏州古城的小范围真实快照，打包具名地点与可步行路网。OpenStreetMap 贡献者署名随网页与导出展示，派生快照和构建器随仓库公开。公网不使用高德 Key，不在规划时向 OpenStreetMap 公共 API 请求数据。

步行估算使用快照最大相连的城区路网和短距离接驳。初次测试发现苏州园内最近节点可能不接公共路网；改为以可达城区路网接驳并限制接驳距离，仍找不到路线时保留未知。时间是步行估算，非实时交通或可进入性验证。

真实行程单含出行信息、逐日日期、地点与地址、餐饮和转场、出发前核对清单。缺实时营业、预约、报价与城际、住宿供给时继续标为待核实。DeepSeek 当日价格复核与账本一致，价格卡下一次核对截止 2026-12-11。

首次全量回归捕获旧测试把 WGS84 视为非法。现在坐标模型区分 WGS84 与 GCJ-02，高德格式转换仍拒绝 WGS84。更新相应回归并完整复测。生产 Neon 独立于预览，管理员试用总上限6个规划，单次5元服务估算上限不变。
