# 2026-11-08：受控网页读取与证据分层

## 本次目标与交付

继续 M2 的网页正文读取待办。实现 DeepSeek Fetch 独立适配器与 `travel-agent-page --live` CLI；首轮只允许两个精确公开网址，不接任意 URL，不增加交易、对外 HTTP 或单 Agent 自动读取工具。

复用费用预留账本、请求大小限制、安全错误码和精确引文定位。新加 HTTP 404/408/413/504 等 Fetch 错误语义，保持其他来源适配默认映射不变。对正文不静默截断，遇到无内容、格式错误、超限、限流或访问策略拒绝停止。

默认只输出和保存最小元数据。正文、供应商标题和输入引文不自动进入 SQLite；显式 `--include-content` 只影响终端展示，不赋予归档或传播权限。来源请求策略和价格卡到 2026-11-15 有效，过期需重新核对。

## 实际核对的能力和缺口

核对 [DeepSeek Search & Fetch](https://api-docs.deepseek.com/guides/search/) 与 [人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。Fetch 返回标题和 Markdown，人民币每千次成功请求 5 元，但没有提供最终网址、跳转链或签名。因此明确标为供应商转换正文，请求网址经过审查不代表返回内容的官方身份已认证。

本轮候选页面为 [南京博物院参观页](https://www.njmuseum.org.cn/zh/visitIndex) 和 [南京市政府门户 2024 年预约相关新闻](https://www.nanjing.gov.cn/njxx/202407/t20240704_4706024.html)。前者保留场馆站点候选身份，未取得独立域名官方认证；后者是历史新闻，不把其中的概括直接当作当前场馆规则。搜索中出现的其他旧域名未自动加入读取范围。

正文采集、引文定位、来源归属、语义支持和出行日期适用性分开报告。政府旧新闻中的概括存在范围与例外；精确找到几个字不表示足以支持“某馆不需预约”。本轮没有自动语义核查，不把这些结果写成事实已核实。

设计与用法见 [ADR-0007](../decisions/0007-bounded-provider-page-reading.md)、[PAGES.md](../PAGES.md)。

## 验证过程

新测试覆盖固定供应商端点、精确网址边界、未知最终来源、不自动保存、单次调用、预算共享、过期价格/读取策略、HTTP 错误、空内容/错误 JSON/超限/Unicode、码点区间、重复歧义、否定例外不升级事实、最小审计和 CLI 退出状态。旧测试继续覆盖用户资料授权及搜索、地图、单 Agent 的行为。

第一轮新增测试中的无效 Unicode 样例在模拟 HTTP 响应构造时就编码失败，尚未到达被测的 Fetch 解析逻辑。改为发送合法 JSON 转义后的孤立代理码点，让测试实际经过响应解析并触发安全拒绝；未放宽程序校验。

初轮统一全量 305 项通过、覆盖率 98.07%。之后补充共享小额账本连续读取直至耗尽的回归，最终结果、安装包与远端 CI 待后续补记。未部署。

最终本地统一检查：静态、格式、依赖一致性、冒烟 10 项、固定回归 31 项、全量 306 项通过，无测试警告；子集不重复计数。语句与分支合并覆盖率 98.07%。wheel/sdist 构建成功，独立环境按锁文件约束安装 wheel，已验证新模块确从 site-packages 导入、CLI 显式联网门槛、模拟读取与最小审计，安装检查无真实网络调用。

检查了 26 份文档的本地链接和两种构建归档，未发现真实密钥或私有配置/运行目录。构建工具继续提示源码树内缓存可能入包，实际归档仍排除了缓存、`.env`、数据库和生成目录，没有隐藏提示。远端 CI 按本轮实际实现 SHA 后续补记，旧提交结果不替代本轮验收。

## 后续阻塞

Fetch 尚未加入单 Agent，不能声称模型已使用网页正文。真实响应快照留存许可、官方身份独立证明、语义充分性与时效核查、独立保留评测及完整旅游覆盖仍未完成。上一轮真实规划的交通冲突与偏好满足问题也未因本轮读取成功而解决；M2 与上线保持未完成。
