## 本次交付

受控单 Agent 串行基线：DeepSeek 返回真实工具调用，服务端只允许搜索、固定城市地点、已返回地点之间步行和提交计划；工具结果以对应调用 ID 回传。不支持购买、发消息、升级、任意代码或 URL 访问。

模型仅选择来源 ID、建议时段和可选逐字摘要引用。程序填地图地点名称/地址，检查日程覆盖、重叠、每日活动数、引用片段及步行衔接。未知营业、预约、费用、住宿、无障碍及跨城交通保持未知；行程只作为草案，不承诺预算满足。

加入 2 元微元账本、价格有效期、单运行缓存、调用/输入上限和停止规则。默认最多 4 次模型、5 次来源；账本串行内存实现，不声称支持多进程共享。当前高德免费模式依赖账号没有付费回退，本地开关不能改变控制台套餐政策。

输出 JSON/Markdown，SQLite 只保存最小运行元数据和来源索引，不默认保存用户输入、提示、行程、私有思维链或原始响应。

## 调研与定价依据

2026-11-08 核对 [DeepSeek 工具调用](https://api-docs.deepseek.com/guides/tool_calls/) 和 [人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。Flash 估算按最高时段输入未命中 2 元/百万、输出 8 元/百万 tokens；搜索 5 元/千次。价格卡暂有效至 2026-11-15，过期阻止调用，不自动沿用。

请求前以较大的输入 token 额度和最大输出来预留，返回后按实际用量高价估算。此模型预算不是供应商账单封顶，实际价格、tokenizer 和免费配额都有外部依赖；费用未知时保留预留并停止后续步骤。实际账单金额未核对，不把估算写成实际扣费。
