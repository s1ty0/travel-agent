# 2026-11-08：正文进入单 Agent 规划回合

## 本次交付

将受控 Fetch 接入单 Agent，保留默认不开启的对照基线。规划输入新增 `page_urls`，最多两个已审查精确网址；只有用户明确列出才开放 `read_page`。普通导入链接、搜索发现的链接和网页指令不能扩大读取范围。

网页与模型、搜索、地图共用一个 2 元账本及来源调用上限。成功读取按运行内参数缓存；失败、费用未知、来源次数耗尽或读取策略过期立即停止，不重试。读取后如模型请求将超过 48000 UTF-8 字节，停止剩余来源和后续模型，不静默截断。

程序检查实际取得的 Markdown 版本里的逐字引用，保留码点区间、行号、指纹和 `provider_markdown` 类型；未读取的地址不能凭 URL 支持引文。搜索摘要、用户资料和供应商正文采用同一精确定位规则，可用 `start_offset` 排除重复歧义，空白引文拒绝。

网页只在模型回合内保留正文。最终 JSON、Markdown 来源面板和 SQLite 审计包含读取状态、获取时间、哈希及父子运行关联，不自动保存正文、供应商标题、原始提示或完整对话。生成方案的终端输出仍可能含模型选择的引文摘录，需在私有位置使用。

最终 `service_cost` 是整次规划总计，子读取标为费用已包含，不重复列出可误加的累计费用。`model_context_status=request_attempted` 表示本地模型请求尝试带上正文，不宣称供应商实际理解或已核实事实。

决定见 [ADR-0008](../decisions/0008-planner-page-tool-and-shared-budget.md)；用法见 [PLANNER.md](../PLANNER.md) 和 [PAGES.md](../PAGES.md)。
